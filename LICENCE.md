## 🧩 About

**RF Online Menu Hub** is a curated list of RF Online open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap markers, stat monitors
- **Quality-of-Life Helpers** — inventory sorter notes, chat filter configs, UI customization
- **Research Notes** — race builds, skill rotations, and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Combat Helpers
- Target Info Overlay — show selected target stats and distance
- Skill Cooldown Tracker — monitor ability timers
- Damage Log Notes — record and review combat events
- Range Indicator — visualize attack ranges for study

### 🎨 UI & Inventory
- Custom UI Layouts — rearrange HUD elements
- Inventory Sorter — organize items by category
- Chat Filter — highlight keywords in chat
- Minimap Markers — add custom waypoints

### 🏋️ Progression & Economy
- Quest Tracker — track objectives and progress
- Loot Logger — record drops for analysis
- Market Watch Notes — monitor auction house prices
- Build Planner — plan stat and skill allocations

3. Launch RF Online.
4. Run the helper on Windows.
5. Press `Tab` or `Insert` to open the overlay menu.

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
| `process_name` | String | `"RFOnline.exe"` | Target process |
| `safe_mode` | Boolean | `true` | Keep conservative defaults |
